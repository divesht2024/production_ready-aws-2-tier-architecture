# 🚀 Deployment Steps

## 1. Network Setup

* Created custom VPC
* Created 2 public subnets across Availability Zones
* Created 2 private subnets for application layer
* Attached Internet Gateway
* Created NAT Gateway for outbound internet from private subnets
* Configured public and private route tables

## 2. Security Setup

* Created ALB Security Group
* Created Application Security Group
* Created RDS Security Group
* Configured least-privilege inbound rules

## 3. Compute Setup

* Created IAM Role for EC2 instances
* Created Launch Template
* Added User Data script to install web server
* Created Auto Scaling Group across private subnets

## 4. Load Balancer Setup

* Created Target Group
* Registered EC2 instances automatically through ASG
* Created Application Load Balancer in public subnets
* Attached listener on port 80

## 5. Database Setup

* Created Amazon RDS instance
* Used private DB subnet group
* Allowed database access only from application security group

## 6. Monitoring Setup

* Enabled CloudWatch metrics
* Built CloudWatch dashboard

## 7. Validation

* Tested ALB DNS endpoint
* Verified healthy targets
* Connected EC2 to RDS successfully
